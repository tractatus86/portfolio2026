Shoe material callout

Making journal · 2026-11-12 · about 3 hours · Illustrator, Photoshop

Making a material callout page for a footwear mock: one product, twenty parts, and how each part is named.

A footwear mock is only as clear as its callouts. This entry follows how one product page went from a pasted shoe photo to a numbered material list.

01

Start from the product

Placeholder paragraph. I cut the shoe from its background and set it on a pale panel. The panel carries the image; the list carries the information. Keeping them separate lets either one change without redrawing the other. Longer paragraphs wrap at a readable measure on any screen, and the text column never gets wider than about 65 characters.

02

Number every layer

Placeholder paragraph. Each part gets a number before it gets a name. Numbers are stable; names change when a supplier changes. The list below is set in Letter Gothic so the numbers line up like a spec sheet.

What I would change

Placeholder paragraph. A second pass would add the supplier and weight beside each number, and a cross-section so the order of the layers can be read at a glance.
